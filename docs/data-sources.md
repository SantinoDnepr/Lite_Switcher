# Источники данных для языковых пакетов и их лицензии

Статус: проверено 2026-10-26 (по первоисточникам, где они были доступны). Основание: ответ 5 в `prompts/prompt004.md` («берём открытые данные с доступными лицензиями, для 1С анализируем `.bsl` в `E:\1c\`»), требование NFR-7 из `docs/auto-switching-spec.md`.

Это инженерная проверка, не юридическое заключение. Перед первым коммитом словарей каждую строку со статусом «проверить» нужно закрыть по тексту лицензии из скачанного файла.

## 1. Правила

1. В репозиторий коммитятся только **частотные срезы** (небольшие бинарные `words.fst`, `ngram3.bin`) и текстовые `pack.ini`, `seed.txt`, `exceptions.txt`. Исходные корпуса и выгрузки не коммитятся.
2. **Локальный лексикон проекта** (идентификаторы из личных конфигураций 1С) не коммитится никогда: каталог `ProgrammingLanguages\1c\local\` в `.gitignore`.
3. Каждый пакет в `pack.ini` указывает `license` и `sources`; общий список источников и текст атрибуции лежат в `NOTICE` (создаётся на этапе 5).
4. Код остаётся под MIT (`Cargo.toml`), данные пакетов лицензируются отдельно (файл `LICENSE-DATA`): **CC BY-SA 4.0**, если среди источников есть материал под этой лицензией. Файла `LICENSE` в репозитории пока нет: добавить до публикации.
5. Данные с лицензиями **NonCommercial** (NC) и данные без указанной лицензии не используются.

## 3. Что показали замеры по данным (2026-10-26)

Подробные таблицы и методика: `docs/auto-switching-architecture.md`, разделы 2 и 12.

- **Английский и русский списки подходят.** После отсечения шума по частоте (≥30 вхождений) получается 111 тыс. английских и 132 тыс. русских слов. Бинарные словари занимают 0,84 МБ и 1,2 МБ.
- **Украинский список мал.** Всего 98,6 тыс. слов с частотой ≥3 и 13,4 тыс. с частотой ≥30 (против 132 тыс. у русского при ≥30). Для пакета `uk` выбран порог 8 вхождений: 38 462 слова, условие FR-L9 (≥ 30 тыс.) выполнено, но словарь шумнее русского и английского. Второй источник (Wikipedia uk, Leipzig uk после проверки лицензии) улучшил бы пару uk↔ru.
- **Шум в списках.** В необработанных списках из субтитров встречаются мусорные токены (например, транслитерация), из-за которых неверный рендер слова иногда сам оказывается «словом». Поэтому `dictgen` обязан отсекать по частоте и по алфавиту пакета.

## Решения заказчика (этап 5)

- Лицензия данных литературных пакетов CC BY-SA 4.0 принята; код под MIT (`LICENSE`).
- Словарь 1С (`ProgrammingLanguages/1c/words.fst`, `pack.ini`) в git не коммитится: он собирается локально из seed, имён платформы (`mcp-dump`) и закрытого кода `E:c`. В git остаётся только `seed.txt`. Вопрос о лицензии на имена платформы из MCP поэтому не блокирует публикацию: имена не распространяются.
